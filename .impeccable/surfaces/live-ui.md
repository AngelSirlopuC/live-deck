# Surface: live UI (audience app, presenter console, screen, remote)

Mode: Operate. Audience on phones in a dim room with a projector; presenters on a laptop.

## Direction contract
THESIS: The chrome is a radio studio desk around the slide: the slide is what is on air, everything else is a console. Refuses the generic floating-toolbar app.
OWN-WORLD: Warm charcoal desk (#14110d, #1f1a14, panels #2a241c), cream engraved legends (#efe4cc), amber backlit keys for active state (#ffb547), the red ON AIR lamp (#ff3b2f) reserved for live status only, green signal (#5fd38d) for connected/correct. Condensed caps legends (Oswald), Instrument Sans body, JetBrains Mono for counts and timers only.
STORY: The audience sees at a glance whether they are on air with the presenter (lamp lit) or exploring on their own (lamp dark, "Volver al aire" key), and can always get back in one tap.
FIRST VIEWPORT: Phone portrait: lamp + title strip, 16:9 slide, a two-position key switch En vivo / Explorar, then the participation panel. Landscape: slide fills the screen, keys fade in on tap. Console: program monitor left, next-slide monitor + notes + timer right, transport keys bottom with End set apart.
FORM: Assigned direction (#5 of own list: radio studio on-air desk), seed 1ece6a20. Signature interaction: the ON AIR lamp warming up when the presenter starts and dimming when the user goes Explorar. Motion grammar: lamp glow warm-up, keys depress 1px with inner shadow, VU needles for reactions (later).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
